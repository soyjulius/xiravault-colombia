# xiravault-colombia
Kit Open Source y búnker digital desconectado (Off-Grid) para la resiliencia familiar, comunitaria y de preparacionistas en Colombia. Repositorio portátil con manuales de medicina táctica, agricultura, energía solar, mapas offline y redes de radioaficionados para operar 100% sin internet ante graves emergencias, crisis locales, sismos y apagones.
